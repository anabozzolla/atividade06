O que é Git?

O Git é um sistema de controle de versões que permite acompanhar as mudanças feitas em um projeto ao longo do tempo. Com ele, você pode registrar alterações, consultar versões anteriores e organizar seu código com mais segurança. É uma ferramenta essencial para quem está aprendendo programação e para profissionais da área de tecnologia.

Conheça os principais comandos

Com os comandos certos, você consegue acompanhar alterações, salvar versões do seu projeto e compartilhar seu trabalho. Estes são os principais para começar:

  • git init - Inicia um repositório Git na pasta atual, permitindo acompanhar as versões do projeto.
  • git add - Seleciona os arquivos e as alterações que você deseja incluir no próximo commit.
    exemplo: git add .
  • git commit - Registra uma versão das alterações preparadas, com uma mensagem que descreve o que foi feito.
    exemplo: git commit -m "Adiciona página inicial"
  • git push - Envia seus commits para um repositório remoto, como o GitHub.
  • git pull - Busca as atualizações do repositório remoto e tenta integrá-las ao seu projeto local.

Git na prática

Comandos para o dia a dia

Criar um repositório

                        
                            git init
                            git add .
                            git commit -m "Primeiro commit"
                            git remote add origin URL_DO_REPOSITORIO
                            git push origin main

Salvando alterações no projeto

                        
                           git status
                            git add .
                            git commit -m "Atualiza o layout do site"

Enviando atualizações para o GitHub

                        
                           git push origin main

Baixando um projeto do GitHub

                        
                           git clone URL_DO_REPOSITORIO
                            cd nome-do-projeto

Atualizando o projeto com alterações de outras pessoas

                        
                           git pull
